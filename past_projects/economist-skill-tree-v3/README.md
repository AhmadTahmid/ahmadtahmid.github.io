# The Economist's Skill Tree V3

A gamified character builder for economics students — allocate skill points to unlock career paths!

## Features

- **Skill Point System**: Click "+1 Point" to gain points, then allocate to pathways
- **Three Pathways**: Theory 📚, Math 🧮, Software 💻
- **Seven Career Classes**: Each with unique requirements and special abilities
- **Educational Content**: Real career advice and skill descriptions
- **Dark Academia Theme**: Cozy visuals with pixel accents

## How to Play

1. Click **+1 POINT** to gain skill points
2. **Allocate points** to Theory, Math, or Software pathways
3. **Unlock classes** when you meet their requirements
4. Click pathways to see **skill details** with tips
5. Click classes to see **abilities, salaries, and employers**

## Local Development

```bash
npx -y serve .
```

Then open `http://localhost:3000`
